## Running Locally
Set the public username and build, then serve the generated folder:

```powershell
$env:PORTFOLIO_GITHUB_USERNAME = 'pueblolaiza'
node scripts/build.mjs
python -m http.server 8000 --directory dist
```

Visit `http://localhost:8000`. Node.js is needed for the build; Python is only the optional local server. No npm installation is required. `.env.example` is documentation and is not loaded automatically. Run the build again after edits. Stop the server with Ctrl+C.

## Deployment
The existing Vercel project is `pueblolaiza/personal_cv`, connected to the GitHub repository’s `main` branch. Its public production URL is listed above.

Use the repository root and static/Other framework preset. `vercel.json` sets the build command to `node scripts/build.mjs` and the output directory to `dist`. The public variable `PORTFOLIO_GITHUB_USERNAME=pueblolaiza` is configured for Preview and Production. No private API token or database is needed.

Pushes to `main` deploy Production; feature branches deploy Preview. Module 3’s actual missing-variable error, corrected Preview, merge to Production, rollback, and restoration are recorded with original CLI evidence in `module3-submission/`. Browser dashboard screenshots remain to be captured manually because automation timed out.

Google Fonts has system font fallbacks. Public GitHub data has a loading state, unavailable message, and retry. A temporary API outage does not disable the portfolio.
